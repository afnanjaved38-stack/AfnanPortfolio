# Afnan Javed — Personal Portfolio

Official website: https://afnanjaved.com/

A lightweight static portfolio for Afnan Javed, founder of Dinaaro and EduPulse, featuring business collaborations, working approach, an About section and contact links.

## Structure

- `index.html`: semantic portfolio content, metadata, social sharing tags, and structured data.
- `styles.css`: responsive presentation.
- `script.js`: mobile navigation and copyright year.
- `assets/favicon.svg`: source of the transparent `AJ` monogram used in the header and as a browser icon.
- `assets/favicon.png`: a 96 × 96 PNG of the same mark for search/favicon compatibility.
- `assets/afnan-portrait-clean.webp`: main profile image.
- `assets/afnan-about-portrait.webp`: About section portrait.
- `robots.txt`: crawler access rules and sitemap location.
- `sitemap.xml`: canonical homepage URL.
- `llms.txt`: optional plain-language site summary for tools that choose to consume it; not a Google ranking factor.
- `CNAME`: custom domain for GitHub Pages.

## Publish

Deploy the root of the `main` branch with GitHub Pages. Set the custom domain to `afnanjaved.com` in repository Settings → Pages. Set up DNS with the domain provider, wait for HTTPS provisioning, and enable Enforce HTTPS. See [GitHub Pages custom domain docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

Verify `https://afnanjaved.com/` and submit `https://afnanjaved.com/sitemap.xml` in Google Search Console after the domain is live. Search ranking and a knowledge panel are not guaranteed.

## Content accuracy

Only publish measured impact as verified evidence. The educational reach numbers currently displayed are labelled illustrative. Dashboard images are visual concepts, not real screenshots. Confirm `hello@afnanjaved.com` mail delivery and target product URLs before publicly promoting the site.
