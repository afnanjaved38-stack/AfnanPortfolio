# Afnan Javed Portfolio

Personal portfolio preview for https://afnanjaved38-stack.github.io/AfnanPortfolio/

Static HTML/CSS/JavaScript. No build tools needed.

## Deployment
GitHub repository Settings → Pages → Deploy from a branch → main → / (root).

## Pending image
Upload the existing transparent portrait as `assets/afnan-portrait-clean.webp` (from the previously delivered V2 ZIP). The site intentionally does not substitute a different person. Until uploaded, the hero displays a fallback label.
