# Portfolio SEO Plan

## Primary goal
Build a clear, trustworthy search result for “Afnan Javed” and connect the person's name with founder and product-building work without making the portfolio look like a Dinaaro-only website.

## Current on-page setup
- One canonical homepage: https://afnanjaved.com/
- Unique title and meta description
- Open Graph and Twitter large image metadata
- Person, ProfilePage, WebSite and Dinaaro SoftwareApplication structured data
- XML sitemap and robots.txt
- Semantic page sections and descriptive headings
- Internal anchor navigation
- Descriptive image alt text
- llms.txt with factual context and project links

## Priority actions
1. Verify the live site in Google Search Console and Bing Webmaster Tools.
2. Submit https://afnanjaved.com/sitemap.xml in Search Console.
3. Inspect the homepage URL and request indexing after deployment.
4. Ensure the canonical URL, HTTPS version, and preferred domain resolve consistently.
5. Keep LinkedIn and Instagram display names, profile links, and biography aligned with the portfolio.
6. Add a professional public profile image and use the same image consistently across the site and social profiles where appropriate.
7. Ask relevant clients or collaborators to link to the portfolio when it is natural and appropriate. Do not buy links or create fake profiles.
8. Publish occasional useful, original updates on LinkedIn and Instagram that link to a relevant project or the portfolio. Prioritize real work and clear context over keyword stuffing.
9. Add real project screenshots and the school recognition document only after confirming permission, accuracy, and the exact school name.
10. Review search queries, impressions, clicks, and indexed pages monthly. Update content based on real evidence.

## Search themes to support naturally
- Afnan Javed
- Afnan Javed founder
- Afnan Javed software products
- Dinaaro founder
- Dinaaro retail management software
- business software and custom digital systems

Do not repeat keywords unnaturally or imply rankings that have not been achieved.

## Technical checks
- Test mobile usability and keyboard navigation.
- Validate JSON-LD with Google's Rich Results Test and Schema.org Validator.
- Validate sitemap and robots.txt after publishing.
- Check social preview cards.
- Keep images compressed and sized to the displayed dimensions.
- Monitor Core Web Vitals and avoid adding heavy third-party scripts.
- Recheck external links and client facts before each major update.

## Limits
This plan improves discoverability and consistency; it cannot guarantee rankings, a knowledge panel, or a specific search position. Search Console and analytics setup requires the site owner's account access.
